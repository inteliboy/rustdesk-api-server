Logs

Reported by the RustDesk client on the controlled device, for devices you own or that are shared with you. Requires that client's API Server to point at this server.

What happened in the WebUI and the management API, newest first: sign-ins, changes to devices, users and settings, and other actions of administrators. Old entries are removed automatically (AUDIT_LOG_RETENTION_DAYS) and cannot be deleted by hand. Export last 30 days (CSV)

Direction is from the controlled device's point of view. The client reports only the path on the controlled device; the controlling side's own path is not sent. Files copied and pasted through the clipboard are reported by name only, with no path.

Security alarms raised by the controlled device when it refused a connection attempt: a blocked IP or ID (whitelist), too many wrong passwords, or a request outside the session's scope. The client only sends these to a self-hosted API server. Who is listed as refused is what the connecting side claimed, so treat it as a lead rather than proof.
