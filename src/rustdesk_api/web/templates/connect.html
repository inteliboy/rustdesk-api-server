Deploy clients

Everything a RustDesk client needs to know about this server, as one string, a QR code and ready-to-run commands. Nothing here is a password: the key is the public key of your ID server.

Your servers

The fields start with what the server is configured with (RUSTDESK_ID_SERVER, RUSTDESK_RELAY_SERVER, RUSTDESK_KEY and EXTERNAL_URL). Changing them here changes only what is shown on this page.

    Config string

    Paste it in a client’s Settings → Network → ID/Relay server (“Import server config”), or use it with --config below.

    QR code

    For the mobile apps’ scan button.

    Set up a computer

    Run these on the machine, as administrator (Windows) or root (Linux and macOS), after installing RustDesk. Try them on one machine first. The --config option needs the installed client; restart RustDesk afterwards if it is running.

    For --assign create an enrollment token first and put it where <TOKEN> stands. The token is not shown here on purpose.

    Or rename the Windows installer

    A RustDesk executable named like this configures itself when it starts, with no command to run.

    Windows installer

    Makes a setup file (.exe) that installs RustDesk and applies the servers above, so nothing has to be typed in on the computer. It downloads RustDesk’s MSI from GitHub and wraps it with NSIS. Try it on one machine first: it removes an installed RustDesk before it installs.
