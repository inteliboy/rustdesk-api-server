API keys

A key lets a script call this server's /api/v1 API as you, with Authorization: Bearer …. A read key can only fetch data. A key cannot manage your account (keys, sessions, two-factor), and it is shown only once.

Enrollment tokens

A token for rustdesk --assign --token …: it lets a script put a device into your address book or group (or, for an administrator, assign it to any user). It cannot be used for anything else, and it is shown only once.
